Choose your routing method.

Select PCC for connection-based load balancing, or Recursive Routing for probe-based WAN failover. Configure four uplinks and generate a RouterOS v7 script for review.

WAN, LAN & routing settings

Enter actual interface names and gateway IPv4 addresses. Recursive probes must be reachable public IPs that respond to ICMP.

PCC distributes new connections across WANs. Recursive routing monitors probe reachability and switches to a lower-priority route when a probe fails.

Rule options

PCC distributes connections, not individual packets. A ratio sets bucket assignment proportions; it does not guarantee identical throughput or automatic failover.

Production warning: Example gateways are documentation-only addresses. Replace them with real gateways. The generated output is a template; verify rule order, routing tables, gateway reachability, FastTrack, existing mangle/NAT rules, DHCP/PPPoE behavior, VPN/BGP exceptions, and failover health checks before deployment.
